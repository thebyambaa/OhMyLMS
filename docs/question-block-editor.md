# Quiz and question form editors

See [ASSESSMENT-MODULES.md](ASSESSMENT-MODULES.md) for source module boundaries, public interfaces and extension guidance.

Gutenberg is now the default for quiz and standalone bank-question authoring. **Add Quiz** and question-bank creation/edit actions open WordPress’s actual editor. See [Gutenberg authoring](GUTENBERG-AUTHORING.md) for the current workflow. The form workspace described below remains available only through the temporary rollback setting.

The Questions tab uses a Wayground-style overview: question and point totals, Create question controls, numbered cards with type and points, prompt summaries, answer options and correctness indicators. Each card provides Preview, Duplicate, Remove, keyboard or drag reorder, and Edit actions. The right-hand Find questions panel searches this quiz by prompt or type and opens the existing question bank picker. Edit opens the fullscreen question workspace; Save question returns to the overview. Version controls remain available for the selected question.

Click **Create question**, search or browse the Basic, Interactive and responses, Mathematics, Visual learning, and Content and multimedia groups, and choose a type to insert a configured draft. The question bank uses the same chooser. Use the labeled **Question type** dropdown to change the response format. Required remains a question setting. Duplicate creates an independent draft, including new answer rows; removing a saved question only removes its quiz placement. Drag reorder is disabled while filtering; clear the search to move questions. The reorder handle also accepts Up/Down arrow keys, and labeled move buttons remain available.

Question authoring uses a large prompt canvas and colored answer cards, with a visible type selector and a footer for preview and save/status. Math, visual and interactive types keep their own configuration panels within the same workspace. Additional settings are collapsed below the answers. Quiz introductions retain their form fields. Prompt formatting includes bold, italic, underline, lists, superscript, subscript and images from the WordPress media library. Existing saved HTML, including content previously authored with blocks, is retained. Question settings are available below the response fields. Quiz settings are below the introduction. Answer controls continue to write through the assessment engine and versioned question writer.

Questions now open in a fullscreen stage with Preview and Save question in the top toolbar. Save question returns to the quiz once autosave finishes. Settings → Design → Quiz & Question Editor provides separate editor and player palettes. Quiz introduction settings select Playful (the default), Classic, Paper or Focus player templates. See [quiz-player-templates.md](quiz-player-templates.md) for configuration, extension points and verification.

Quiz and bank creation offer all 38 built-in formats. The original 24 include choice, written, numerical, structured, sentence, table and visual mathematics formats. The additional 14 are passage, graphing, hot text, match table grid, labeling, hotspot, draw, audio response, video response, poll, word cloud, discussion board, slide and interactive video. Changing type resets that card's answer setup; unscored poll, word cloud and slide formats reset marks to zero. Existing question versions and custom extensions retain their assessment contracts.

Single choice and multiple choice now share one **Multiple select** entry. The bottom-left **Multiple correct answers** switch changes selection mode while preserving authored options, media and IDs. Turning it off retains the first correct answer. The conditional **Allow partial grading** switch defaults off and awards `(correct selections − incorrect selections) / total correct answers`, bounded at zero. Duplicate submitted IDs cannot inflate credit. Exact selection remains required when partial grading is off. Legacy `single-choice` and `multiple-choice` identifiers remain stored and supported; the unified chooser has 37 entries covering the existing 38 format contracts. Published question snapshots keep their own grading setting.

Extended formats have native learner controls and frozen grading settings. Drawing, recordings and discussion responses await teacher review. Word clouds visualize the current learner's words; discussion responses are individual submissions. Graphing supports points and straight lines. Passage uses structured numerical, expression and written parts; video checkpoints use text responses. These scopes differ from Wayground's live classroom and advanced graphing features. See [question-editor-verification.md](question-editor-verification.md) for saved comparison artifacts, tests and remaining parity limits.

Use **Preview question** and **Edit question** to switch between editing and the learner response layout. Preview uses unsaved title, prompt and answers. Responses in preview are temporary and are neither saved nor graded. Correctness flags, numerical expected values and teacher marking notes are excluded from preview. Inline blank solutions in the title are replaced with inputs. Preview uses static prompt HTML; dynamic shortcodes and server-rendered embeds still require page preview for final output, and site theme styling may differ.

The quiz header's **Preview** button opens the shipped learner quiz player directly in an author-only preview session. Save changes first: it previews saved questions and settings. It uses the same question renderers, page layout, Next/Previous navigation, required-answer checks, matching controls, timer and Submit controls as the normal player. It does not open a course page or require **Start Quiz**, enrollment or an available learner attempt.

Submitting preview grades the frozen preview questions on the server and shows a temporary score; manual answers remain pending. It creates no learner attempt, grade event or skill evidence and does not publish a quiz revision. **Try again** starts a fresh preview; the player's close control and **Exit** return to the quiz editor. Sessions expire after one hour. Already-open editor tabs must be reloaded after an editor update to load the current Preview action.

The authored media picker opens WordPress media directly because the standalone forms have no Gutenberg MediaUpload provider. Recovered vendor Lodash globals are released through their public `noConflict()` method before opening media so WordPress retains Underscore callback contexts; recovered runtime bundles are not modified. New answer rows receive temporary IDs, which are removed by the existing versioned writer before persistence. Preview guards numeric visual-model part counts separately from structured part arrays.
