# Syllabus skill directory

A syllabus is displayed as a grade or subject skill collection. Regular courses keep their existing course page.

1. Open the syllabus in Content Hub and choose **Syllabus Settings**.
2. Set its grade/level, subject and language. On the syllabus home, create category tags below Code and Version by typing a name and pressing Enter. Skills select from this list; they cannot create categories. Use × to remove an unused category; reassign skills before removing a category they use. Organize skills into topics and chapters, and assign categories such as Core, Extended or Advanced.
3. Choose **Preview skill directory** to review the draft. Preview requires curriculum administrator access.
4. Choose **Publish syllabus** (or **Publish syllabus changes**) when ready. Publishing saves a directory snapshot alongside the learning program. Subsequent draft edits stay private until republished.
5. Share **View published syllabus**. The standard course permalink also displays the directory when the syllabus has a published directory snapshot. Existing published syllabuses must be republished once to create their first snapshot.

The standalone URL is `/?ohmylms_syllabus=SYLLABUS_ITEM_ID`. A page can also embed `[ohmylms_syllabus id="5"]`. These IDs refer to curriculum syllabus items, not course post IDs. Password-protected and unpublished courses cannot be browsed through the directory URL or shortcode.

Search matches skill names and codes; categories combine with the search. Empty topics and chapters are omitted. Published syllabuses appear in the grade/level navigation. Custom topic and chapter icons are retained.

Selecting a skill opens existing catalog practice with a link back to the directory. Question approval, public practice flags, bank visibility and learner access continue to apply. Publishing a directory does not make private questions public. Add approved questions and configure their practice access before expecting learners to practise a skill. Course-specific learning paths and enrollment remain available separately.
