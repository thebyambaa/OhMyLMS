# Math References

Use Math References for reusable formulas, definitions, and mathematician profiles. Inline links in lessons and posts open a preview card that leads to the full reference.

## Create a reference

1. In WordPress admin, go to **OhMyLMS → Math References → Add Math Reference**.
2. Add a title and write the full explanation in the editor. Add a short **Excerpt** for the card. When the excerpt is empty, the card takes a short plain-text summary from the entry.
3. In **Reference details**, choose **Formula**, **Definition**, or **Mathematician**.
   - For a formula, enter the expression in **Equation in LaTeX (formulas)**, for example <code>x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}</code>. The card and full entry display the formula. With MathLive disabled, they display the LaTeX as text.
   - For a definition, write a concise meaning in the excerpt and use the full entry for examples.
   - For a mathematician, set a **Featured image** to show a portrait on the card.
4. Optionally enter a **Source URL**. It appears as **Reference source** on the full entry. Publish the entry with public visibility so it appears in the picker.

## Link from a lesson or post

1. In Gutenberg, select the word or phrase you want to link.
2. Choose **Math Reference** from the text formatting toolbar, search for the published entry, and choose **Apply link**.
3. Preview or open the published lesson or post. Click the linked text to check the preview. Choose **Read full reference** to open the full entry.
4. To update the link, place the cursor in the linked text and reopen **Math Reference**. Select another entry or choose **Remove reference link**.

You can reuse the same entry in multiple lessons and posts. Changes to the published entry appear in its linked previews. In a browser without popover support, the link goes directly to the full entry. Draft, private, and password-protected entries are excluded from inline previews.

See [MathLive](MATHLIVE.md) for equation rendering.
