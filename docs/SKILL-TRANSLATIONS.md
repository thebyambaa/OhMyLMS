# Skill languages

In a syllabus, select a skill to edit its English and Mongolian learning objectives side by side. Both fields use regular 14px text, share one adjustable height (240px initially, 160–800px), and save independently on blur. Individual resize handles are removed; the shared Resize both textareas slider supports mouse dragging and keyboard arrows, Home, and End. On narrow screens they stack vertically. The redundant original-objective section, short-title field, and objective breadcrumb text are removed from this pane. Their stored data is retained for compatibility. Original, English, and Mongolian icon buttons above the fields control the sidebar and notes. Each textarea contains a direction-specific translation button: English translates from Mongolian, and Mongolian from English. Translation uses the latest opposite objective text, including its current edit, and opens an editable draft in the destination column. Save translation writes only that objective; Discard draft keeps the saved text. A missing translation shows the original as a starting point; editing it saves only that language.

Language variants live in `_ohmylms_skill_translations` WordPress term metadata (`en` / `mn`, each with `name`, `description`, and optional `objective`). No table, duplicate skill, ID migration, or assessment snapshot change is needed. The canonical taxonomy name and description remain the Original version. Short titles retain the 190 character limit; objectives and notes allow 2000 characters. Original objective overrides use `_ohmylms_skill_objective` metadata, retaining the taxonomy title and notes. Updating one translation field preserves other fields and languages.

Automatic translation uses the existing enabled AI provider, model, key and token settings. The author-only POST `/ohmylms/v1/skills/{id}/translate` accepts a bounded source and target language, returning a draft without saving it. The UI lets the teacher edit, save or discard the objective draft in its destination column; generated short titles and notes are not saved by these objective-only buttons. Configuration and provider failures leave manual editing available. Translation is per skill; this does not bulk translate a syllabus or automatically choose a language on learner pages. Existing CSV exports continue to export the Original version.

`includes/Skills/Translations.php` retains the repository's PSR-4 class/file mapping. Its PascalCase filename is a narrow compatibility exception to WordPressCS filename conventions; the findings are reported without suppression.
